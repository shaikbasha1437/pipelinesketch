# shop_api_to_marts (dbt project)

Orders from the shop API modelled with dbt

Generated by [PipelineSketch](https://shaikbasha1437.github.io/pipelinesketch/). Requires dbt-core 1.10 or newer and dbt-snowflake.

```bash
pip install "dbt-core>=1.10" dbt-snowflake
cp profiles.example.yml ~/.dbt/profiles.yml   # then fill in the env vars
dbt parse
dbt build
```

- Raw tables in `raw` are landed by the orchestrator (Airflow, Dagster or Prefect exports) and declared as sources.
- Transform models build in the target schema (`staging`); warehouse-table sinks build as table or incremental models in their own schema.
- Column checks are generic `data_tests`; row-count, freshness, multi-column unique and custom checks are singular tests in `tests/`.
- Sinks outside the warehouse (files, lakes, Kafka) are documented as exposures.

# ===== models/marts/fct_customer_revenue.sql =====
{{ config(materialized='table') }}

select
    c.customer_id,
    c.segment,
    count(o.order_id) as orders,
    coalesce(sum(o.amount), 0) as revenue
from {{ ref('stg_customers') }} as c
left join {{ ref('stg_api_orders') }} as o
    on o.customer_id = c.customer_id
group by 1, 2

# ===== models/marts/schema.yml =====
version: 2

models:
  - name: fct_customer_revenue
    description: "select c.customer_id, c.segment, count(o.order_id) as orders"
    columns:
      - name: customer_id
        data_tests:
          - unique
      - name: segment
      - name: orders
      - name: revenue

# ===== models/sources.yml =====
version: 2

sources:
  - name: raw
    schema: raw
    description: "Raw data landed by the orchestrator (shop_api_to_marts)."
    tables:
      - name: api_orders
        description: "api.example.com/v1/orders?updated_since={ds}"
        columns:
          - name: id
          - name: customer_id
          - name: total
          - name: currency
          - name: created_at
  - name: ext_crm
    database: ANALYTICS
    schema: CRM
    description: Existing Snowflake tables.
    tables:
      - name: crm_customers
        identifier: CUSTOMERS
        description: ANALYTICS.CRM.CUSTOMERS
        columns:
          - name: customer_id
          - name: name
          - name: segment
