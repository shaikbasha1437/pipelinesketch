# clickstream_medallion (dbt project)

Micro-batch clickstream into a bronze/silver/gold Delta lake

Generated by [PipelineSketch](https://shaikbasha1437.github.io/pipelinesketch/). Requires dbt-core 1.10 or newer and dbt-duckdb.

```bash
pip install "dbt-core>=1.10" dbt-duckdb
cp profiles.example.yml ~/.dbt/profiles.yml   # then fill in the env vars
dbt parse
dbt build
```

- Raw tables in `raw` are landed by the orchestrator (Airflow, Dagster or Prefect exports) and declared as sources.
- Transform models build in the target schema (`staging`); warehouse-table sinks build as table or incremental models in their own schema.
- Column checks are generic `data_tests`; row-count, freshness, multi-column unique and custom checks are singular tests in `tests/`.
- Sinks outside the warehouse (files, lakes, Kafka) are documented as exposures.

# ===== models/staging/gold_activity.sql =====
select
    cast(event_ts as date) as event_date,
    event_type,
    count(*) as events,
    count(distinct user_id) as users
from {{ ref('silver_events') }}
group by 1, 2

# ===== models/staging/schema.yml =====
version: 2

models:
  - name: silver_valid
    description: where user_id is not null and event_type is not null
    columns:
      - name: event_id
      - name: user_id
      - name: event_type
      - name: page
      - name: event_ts
  - name: silver_events
    description: unique event_id by event_ts desc
    columns:
      - name: event_id
        data_tests:
          - not_null
      - name: user_id
        data_tests:
          - not_null
      - name: event_type
      - name: page
      - name: event_ts
  - name: gold_activity
    description: "select cast(event_ts as date) as event_date, event_type, cou"
    columns:
      - name: event_date
      - name: event_type
      - name: events
      - name: users

# ===== models/staging/silver_events.sql =====
select *
from {{ ref('silver_valid') }}
qualify row_number() over (partition by event_id order by event_ts desc) = 1

# ===== models/staging/silver_valid.sql =====
select *
from {{ source('raw', 'clickstream') }}
where user_id is not null and event_type is not null

# ===== tests/gold_not_empty.sql =====
-- gold_activity row count must satisfy: count(*) >= 1
select count(*) as row_count
from {{ ref('gold_activity') }}
having not (count(*) >= 1)
