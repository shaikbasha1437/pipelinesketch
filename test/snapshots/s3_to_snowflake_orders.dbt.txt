# s3_to_snowflake_orders (dbt project)

Daily orders ELT from S3 into Snowflake

Generated by [PipelineSketch](https://shaikbasha1437.github.io/pipelinesketch/). Requires dbt-core 1.10 or newer and dbt-snowflake.

```bash
pip install "dbt-core>=1.10" dbt-snowflake
cp profiles.example.yml ~/.dbt/profiles.yml   # then fill in the env vars
dbt parse
dbt build
```

- Raw tables in `raw` are landed by the orchestrator (Airflow, Dagster or Prefect exports) and declared as sources.
- Transform models build in the target schema (`staging`); warehouse-table sinks build as table or incremental models in their own schema.
- Column checks are generic `data_tests`; row-count, freshness, multi-column unique and custom checks are singular tests in `tests/`.
- Sinks outside the warehouse (files, lakes, Kafka) are documented as exposures.

# ===== models/staging/orders_dedup.sql =====
select *
from {{ ref('stg_orders') }}
qualify row_number() over (partition by order_id order by updated_at desc) = 1

# ===== models/staging/schema.yml =====
version: 2

models:
  - name: stg_orders
    description: 5 columns
    columns:
      - name: order_id
      - name: customer_id
      - name: status
      - name: amount
      - name: updated_at
  - name: orders_dedup
    description: unique order_id by updated_at desc
    columns:
      - name: order_id
        data_tests:
          - not_null
          - unique
      - name: customer_id
        data_tests:
          - not_null
      - name: status
        data_tests:
          - accepted_values:
              arguments:
                values: ["placed", "shipped", "delivered", "returned"]
      - name: amount
      - name: updated_at

# ===== models/staging/stg_orders.sql =====
select
    order_id,
    customer_id,
    lower(status) as status,
    cast(amount as number(12, 2)) as amount,
    updated_at
from {{ source('raw', 'orders_raw') }}

      database: "{{ env_var('SNOWFLAKE_DATABASE') }}"

      schema: staging
      threads: 4
    local:
      type: duckdb
      path: local.duckdb
      schema: staging
      threads: 1
