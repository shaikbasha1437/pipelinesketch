# ad_spend_attribution (dbt project)

Channel spend per customer from two ad platforms

Generated by [PipelineSketch](https://shaikbasha1437.github.io/pipelinesketch/). Requires dbt-core 1.10 or newer and dbt-postgres.

```bash
pip install "dbt-core>=1.10" dbt-postgres
cp profiles.example.yml ~/.dbt/profiles.yml   # then fill in the env vars
dbt parse
dbt build
```

- Raw tables in `raw` are landed by the orchestrator (Airflow, Dagster or Prefect exports) and declared as sources.
- Transform models build in the target schema (`staging`); warehouse-table sinks build as table or incremental models in their own schema.
- Column checks are generic `data_tests`; row-count, freshness, multi-column unique and custom checks are singular tests in `tests/`.
- Sinks outside the warehouse (files, lakes, Kafka) are documented as exposures.

# ===== models/staging/schema.yml =====
version: 2

models:
  - name: ad_spend
    description: union all
    columns:
      - name: customer_id
      - name: channel
      - name: spend
  - name: spend_with_customers
    description: inner join on customer_id
    columns:
      - name: customer_id
      - name: country
      - name: channel
      - name: spend
  - name: spend_by_channel
    description: "channel → search, social, video"
    columns:
      - name: customer_id
      - name: country
      - name: search
      - name: social
      - name: video

# ===== models/staging/spend_by_channel.sql =====
select
    customer_id,
    country,
    sum(case when channel = 'search' then spend end) as search,
    sum(case when channel = 'social' then spend end) as social,
    sum(case when channel = 'video' then spend end) as video
from {{ ref('spend_with_customers') }}
group by customer_id, country

# ===== models/staging/spend_with_customers.sql =====
select
    l.customer_id,
    r.country,
    l.channel,
    l.spend
from {{ ref('ad_spend') }} as l
inner join {{ source('raw', 'customers') }} as r
    using (customer_id)

# ===== tests/has_rows.sql =====
-- spend_by_channel row count must satisfy: count(*) between 1 and 5000000
select count(*) as row_count
from {{ ref('spend_by_channel') }}
having not (count(*) between 1 and 5000000)

# ===== tests/no_negative_spend.sql =====
-- returns failing rows
select *
from {{ ref('spend_by_channel') }}
where search < 0 or social < 0 or video < 0
