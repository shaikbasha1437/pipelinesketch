# customers_cdc_to_bigquery (dbt project)

Incremental customer changes from Postgres into a BigQuery dimension

Generated by [PipelineSketch](https://shaikbasha1437.github.io/pipelinesketch/). Requires dbt-core 1.10 or newer and dbt-bigquery.

```bash
pip install "dbt-core>=1.10" dbt-bigquery
cp profiles.example.yml ~/.dbt/profiles.yml   # then fill in the env vars
dbt parse
dbt build
```

- Raw tables in `raw` are landed by the orchestrator (Airflow, Dagster or Prefect exports) and declared as sources.
- Transform models build in the target schema (`staging`); warehouse-table sinks build as table or incremental models in their own schema.
- Column checks are generic `data_tests`; row-count, freshness, multi-column unique and custom checks are singular tests in `tests/`.
- Sinks outside the warehouse (files, lakes, Kafka) are documented as exposures.

# ===== models/staging/customers_enriched.sql =====
select
    *
from {{ ref('customers_latest') }} as l
left join {{ source('ext_reference', 'countries') }} as r
    using (country_code)

# ===== models/staging/customers_latest.sql =====
select *
from {{ source('raw', 'customers_cdc') }}
where true
qualify row_number() over (partition by customer_id order by updated_at desc) = 1

# ===== models/staging/schema.yml =====
version: 2

models:
  - name: customers_latest
    description: unique customer_id by updated_at desc
    columns:
      - name: customer_id
      - name: email
      - name: full_name
      - name: country_code
      - name: updated_at
  - name: customers_enriched
    description: left join on country_code
    columns:
      - name: customer_id
        data_tests:
          - not_null
          - unique
      - name: email
      - name: full_name
      - name: country_code
      - name: updated_at
      - name: country_name
      - name: region

# ===== tests/customers_fresh.sql =====
-- newest updated_at in customers_enriched must be at most 3 hours old
select max(updated_at) as newest
from {{ ref('customers_enriched') }}
having not (max(updated_at) >= timestamp_sub(current_timestamp(), interval 3 hour))
